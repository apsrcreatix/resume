# Publish your own copy with GitHub Pages

1. **Fork** this repository to your GitHub account.
2. Edit `README.md` with your resume details and update `_config.yml` with your name and GitHub username.
3. In your fork, open **Settings → Pages** and choose the `master` branch and `/ (root)` as the publishing source. Save.
4. Wait for the Pages build, then visit `https://<your-username>.github.io/resume/`.

The profile photo on the page uses `https://github.com/<your-username>.png`, so it follows the current GitHub avatar automatically. To learn more Markdown formatting techniques, see the [Markdown Guide: Hacks](https://www.markdownguide.org/hacks/).
